# Hotspot annotator

A dependency-free page for drawing or correcting a scene's hotspot polygon by hand. Open a
master image, click to place vertices, drag to adjust them, watch the area and safe-area checks
from `dsp validate` update live, and copy the YAML snippet into `content/scenes.yaml`.

Not built yet: the hotspot work package adds `index.html` here. It will open directly in a
browser with no build step.
