    How to edit

    • Click empty space to add a vertex after the selected one; click near an edge to insert a vertex into it.
    • Drag a vertex to move it; click one to select it.
    • Delete or Backspace removes the selected vertex.
    • Arrow keys nudge it by one image pixel (Shift: ten).
    • Esc deselects; Ctrl/Cmd+Z undoes.
    • The dashed box is the safe area the centroid (the cross) must stay inside.
